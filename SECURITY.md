# Security Policy

## Supported Versions

The table below shows the versions of this project that are currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 2.3.x   | :white_check_mark: |
| 2.2.x   | :white_check_mark: |
| 2.1.x   | :x:                |
| < 2.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

- **Email**: [security@yourdomain.com](mailto:security@yourdomain.com)
- **Please do not open public issues** related to security vulnerabilities.

We appreciate your help in keeping this project secure and reliable.
